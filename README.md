# Fraud Website Detector 🔍

## About the Project

Fraud Website Detector is a web-based application developed to help users identify potentially fraudulent or suspicious websites.

The application analyzes website URLs and checks different security-related details to help users make safer decisions while browsing the internet.

## Features

- **SSL Certificate Checking:** Checks whether a website has an SSL certificate.
- **HTTPS Checking:** Checks whether a website uses a secure HTTPS connection.
- **URL Analysis:** Extracts and analyzes website domain information.
- **Misspelled URL Detection:** Identifies suspicious URL spelling patterns.
- **User Interface:** Provides a web interface for interacting with the application.

## How It Works

1. The user enters a website URL.
2. The application extracts the website domain.
3. It checks relevant URL and security information.
4. It analyzes the available results.
5. It helps the user identify potentially suspicious websites.
